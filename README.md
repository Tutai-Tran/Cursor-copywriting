# Cursor Copywriting

Repository purpose: maintain prompt and workflow documentation for AI coding assistants used in Cursor-based development workflows.

## Contents

- `AI_ASSISTANT_GUIDELINES.md`: consolidated operating rules for the assistant, including:
  - communication behavior
  - exploration and editing strategy
  - task management expectations
  - code formatting/citation conventions

## Usage

Use the guidelines file as a baseline prompt policy. Tailor constraints per project language stack, CI requirements, and team review preferences.
